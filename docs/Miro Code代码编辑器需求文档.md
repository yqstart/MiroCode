# 基于TauriVue3桌面代码编辑器产品需求文档

## 1 项目概述

Miro Code（米罗编辑器），是基于 Tauri  Vue3 构建的**轻量化、快速、顺滑、全语法专业桌面代码编辑器**。产品采用 VSCode 经典灵活布局、自主设计的极简低饱和视觉 UI、WebStorm 标准的文件检索与 Git 管理体系，覆盖全主流开发语法的智能编辑能力，兼顾极致性能、极简颜值与专业编码体验。本文档为项目官方唯一品牌定名规范，所有项目文档、源码、产品展示统一使用该名称口径。

> **当前阶段**：核心功能集（资源管理 / 编辑 / 搜索 / Git / 终端·SSH / 主题 / LSP）已收敛，进入**优化迭代期**，后续开发围绕性能、流畅度、交互体验打磨展开，不再扩展大功能模块。远期可能新增 AI 智能提示 / 行内智能补全（编辑器内补全形态，非独立面板）；AI 对话面板、Agent、MCP 等均不做。

### 11 项目定位

本项目为一款轻量化、高性能、跨平台桌面代码编辑器，基于 Tauri  Vue3 技术栈开发。产品布局对标 VSCode 经典布局体系，视觉 UI 采用自主设计的极简现代化风格，核心功能模块（资源管理器、全局搜索、Git 版本管理）对标 WebStorm 交互逻辑与能力标准，同时全覆盖主流前端、配置、文档类文件的语法编辑能力，打造轻量、流畅、功能完备的桌面代码编辑工具。

### 12 技术栈选型

- **核心框架**：Tauri（桌面端跨平台打包、高性能、低内存占用） Vue3（Composition API、组件化开发、高效渲染）
- **布局体系**：对标 VSCode 经典左右分栏、可折叠、可拖拽、自适应布局
- **UI 视觉体系**：极简扁平化、低饱和度配色、轻量化控件、沉浸式编辑界面
- **核心交互参考**：资源管理器、全局搜索、文件查找、Git 管理模块完全对标 WebStorm 交互逻辑与功能体验



### 13 核心目标

- 实现 VSCode 级别的灵活布局能力，兼顾高颜值视觉体验
- 复刻 WebStorm 成熟的文件管理、搜索检索、Git 版本控制核心能力
- 全覆盖主流开发语法，实现高亮、折叠、校验、补全、跳转等全套编辑能力
- 依托 Tauri 优势，实现启动快、内存低、跨平台（Windows/Mac/Linux）的轻量化桌面编辑器
- **主打轻量级、快速、顺滑**：核心功能集收敛后，持续围绕性能、流畅度、交互体验优化，不堆砌大功能模块



## 2 整体产品规范



### 21 布局规范（对标 VSCode）

整体采用 VSCode 经典模块化布局，支持自由拖拽、折叠、显示/隐藏、尺寸自适应，布局状态可记忆保存。

- **左侧功能栏**：活动栏为 Project 与 Commit；侧栏随工具窗口切换。Git Log 作为编辑区标签打开（类 VS Code Git Graph）。支持折叠与调宽
- **中央编辑区**：主编辑窗口，支持多文件标签页、终端标签、Git Log 标签和 markdown 预览
- **底部状态栏**：只展示文件类型、编码格式、行数列数、Git 分支、语法校验状态、错误提示
- **顶部菜单栏/工具栏**：文件、编辑、视图、工具、设置等通用功能，支持快捷操作按钮自定义（第一期先不做）



### 22 UI 视觉规范（极简低饱和）

整体采用现代化极简 UI 设计，统一视觉风格，摒弃冗余元素，主打沉浸式编辑体验。

- **色彩体系**：低饱和主题配色，支持浅色/深色主题切换，代码高亮配色贴合 Miro Dark / Dawn 主题方案
- **控件样式**：极简扁平化按钮、输入框、弹窗、下拉菜单，无多余渐变、阴影，轻量化视觉质感
- **界面层级**：分区清晰，功能区、编辑区、状态栏层级分明，留白合理，视觉通透
- **交互反馈**：hover、点击、选中、折叠等操作反馈轻柔自然，无突兀动画，兼顾流畅度与质感
- **字体排版**：代码字体等宽清晰，界面字体层级统一，字号适配桌面端显示比例



## 3 核心功能模块需求



### 31 资源管理器模块

对照 VSCode 做即可

- **项目导入与展示**：支持打开本地文件夹、导入完整项目，树形结构展示项目文件/目录，自动识别项目层级，支持根目录自定义
- **文件/目录操作**：支持新建文件、新建文件夹、重命名、删除、复制、粘贴、移动文件，操作逻辑与 VSCode 完全一致
- **文件状态标识**：实时展示文件修改状态（未修改、已修改、新增、删除）、Git 状态（未跟踪、已暂存、已提交、冲突），图标标识清晰
- **折叠与定位**：支持目录批量折叠/展开、点击文件快速定位到编辑区、编辑区文件自动高亮定位资源树位置
- **过滤与隐藏**：支持自定义忽略文件/文件夹（如 nodemodules、git、dist），支持关键词过滤检索项目文件
- **右键菜单**：包含在资源管理器显示、复制路径、重命名等



### 32 全局搜索与文件查找模块（对标 WebStorm）

完全参照 WebStorm 双检索体系，区分「文件查找」和「全局内容搜索」，支持精准、高效的项目检索能力。

#### 321 文件查找功能

- 支持全局快速检索项目内所有文件，通过文件名、后缀、模糊匹配查找文件
- 支持快捷键唤起搜索窗口，搜索结果实时刷新，高亮匹配关键词
- 支持筛选文件类型、排除指定目录，点击结果直接跳转打开对应文件
- 保留历史搜索记录，支持快速复用历史检索条件



#### 322 全局内容搜索功能

- 支持项目全局文本检索，在所有文件中匹配指定内容，支持精确匹配、模糊匹配、大小写匹配切换
- 支持搜索结果预览，展示匹配行上下文内容，精准定位代码位置
- 支持批量替换功能，可全局替换指定文本，预览替换效果、确认替换
- 支持排除目录、排除文件类型、限定检索文件范围，提升检索效率
- 检索交互、结果展示、操作逻辑完全对齐 WebStorm



### 33 Git 版本管理模块（对标 WebStorm）

复刻 WebStorm 全套可视化 Git 管理能力，无需命令行即可完成所有常规 Git 操作，交互逻辑、界面展示完全对标。

- **仓库初始化与关联**：支持初始化本地 Git 仓库、关联远程仓库、切换远程地址
- **文件状态管理**：可视化展示所有变更文件（新增、修改、删除、冲突、未跟踪），支持单文件/批量文件暂存
- **基础提交操作**：支持编写提交备注、批量提交、单独提交指定文件，提交记录实时生成
- **分支管理**：支持查看本地/远程分支、新建分支、切换分支、合并分支、删除分支、分支重命名
- **拉取与推送**：支持拉取远程代码、推送本地提交、强制推送、合并冲突提示与可视化解决
- **版本记录查看**：可视化 Git 提交日志，展示提交人、提交时间、提交备注、文件变更明细，支持回滚指定版本
- **暂存与重置**：支持代码暂存、恢复暂存、重置工作区、撤销最近提交
- **冲突处理**：可视化代码冲突对比界面，支持手动合并、保留本地/远程版本、批量解决冲突



### 34 全语法编辑能力（核心能力）

编辑器全覆盖主流开发语法，针对每类语法统一实现 **代码高亮、代码折叠、语法校验、基础代码补全、组件/文件引用跳转** 五大核心能力，无语法短板。

**支持语法全列表**：Vue、Tailwind CSS、HTML、CSS、Sass、JavaScript、TypeScript、JSON、Env 环境变量文件、Markdown、XML、YAML

#### 341 通用基础能力（所有语法统一支持）

- **语法高亮**：精准区分关键字、变量、函数、注释、属性、常量等不同代码元素，配色清晰可辨，贴合主流编码视觉习惯
- **代码折叠**：支持区块折叠、函数折叠、标签折叠、嵌套代码折叠，可手动折叠/展开、全部折叠/全部展开
- **语法校验**：实时检测语法错误、格式错误、不规范写法，红线标注错误位置，悬浮展示错误原因，支持基础语法纠错提示
- **基础代码补全**：关键字、内置方法、属性、语法片段自动补全，回车快速填充，提升编码效率
- **引用跳转**：支持文件引用、组件引用、变量/函数引用点击跳转定义位置，支持返回上一级跳转位置



#### 342 各语法专项能力适配

- **Vue**：支持 SFC 单文件组件完整语法识别，template/style/script 分区高亮，组件导入跳转、props 校验、指令补全、组件标签折叠
- **Tailwind CSS**：支持 Tailwind 所有工具类名高亮、类名补全、无效类名语法校验，支持自定义配置类名识别
- **HTML/CSS/Sass**：标签、属性、样式属性、嵌套语法高亮，样式代码折叠，属性补全，样式引用跳转，格式校验
- **JS/TS**：变量、函数、类型、接口精准高亮，TS 类型语法校验，类型推导补全，函数定义跳转、模块引用跳转
- **JSON/Env**：JSON 格式严格校验、键值高亮、语法纠错；Env 环境变量键值高亮、格式校验、重复变量检测
- **MD/XML/YAML**：文档标签、层级、键值对高亮，区块折叠，格式语法校验，嵌套结构识别，基础片段补全



## 4 非功能需求



### 41 性能需求

- 依托 Tauri 轻量化特性，软件启动时长 ≤2s，大项目（千级文件）加载无卡顿
- 多文件打开、频繁编辑、全局搜索、Git 操作无明显延迟，内存占用远低于 VSCode
- 语法校验、代码补全、跳转功能实时响应，无明显等待延迟



### 42 兼容性需求

- 支持 Windows、Mac、Linux 全平台打包运行
- 兼容主流项目文件格式，支持各类语法最新版本规范



### 43 体验需求

- 所有功能操作逻辑统一，贴合主流编辑器使用习惯，学习成本低
- 布局状态、主题配置、快捷键、搜索记录等用户配置持久化保存
- 错误提示清晰易懂，支持基础问题修复指引



## 5 交付范围

- 基于 TauriVue3 开发的完整桌面编辑器源码
- 适配 VSCode 布局、Miro 极简 UI、WebStorm 核心交互的完整功能体系
- 全覆盖语法的高亮、折叠、校验、补全、跳转能力
- 项目打包配置、跨平台构建脚本

## 6 后续方向（优化迭代期）

核心功能集已收敛，后续不再扩展大功能模块，围绕以下方向持续优化：

- **性能**：启动速度、大目录/大文件加载、内存占用
- **流畅度**：输入响应、滚动帧率、弹层/标签/树动效统一
- **交互体验**：编辑器现存问题修复、Git/终端/SSH 操作体感、视觉细节打磨
- **远期可能**：AI 智能提示 / 行内智能补全（编辑器内补全形态，非独立面板），待优化成熟后单独立项

**明确不做**：AI 对话面板、AI Agent、MCP / Skills 生态、插件市场。
