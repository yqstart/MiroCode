## GitHub 仓库设置（人工）

- [ ] Settings → **Change visibility → Public**
- [ ] About：描述、Topics（建议：`tauri`、`vue`、`codemirror`、`editor`、`desktop`）
- [ ] Settings → Code security → 开启 **Secret scanning** / **Dependabot alerts**（公开后可用）
- [ ] Settings → Code security → **Private vulnerability reporting**（与 `SECURITY.md` 对齐）
- [ ] 确认默认分支保护（可选：Require PR）
- [ ] 打首个 Release 标签 `v0.1.0` 并粘贴 `CHANGELOG` 对应段落（可先「仅源码」、稍后补安装包）
