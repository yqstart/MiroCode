# Miro Code 使用说明

## 快速开始

1. 启动应用：`pnpm tauri:dev`
2. 使用 **⌘O / Ctrl+O** 或欢迎页按钮打开本地文件夹
3. 在资源管理器中点击文件即可编辑

## 主界面

| 区域 | 说明 |
|------|------|
| 活动栏（左侧） | 资源管理器、Git；底部为终端与设置 |
| 侧边栏 | 当前面板内容（点击同一图标可折叠侧栏） |
| 编辑区 | 多标签页：代码文件与「终端」会话同级打开 |
| 状态栏 | 分支、语言、光标、主题 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| ⌘/Ctrl + O | 打开文件夹 |
| ⌘/Ctrl + P | 按文件名查找并打开（Quick Open） |
| ⌘/Ctrl + Shift + F | 在文件中查找（WebStorm 风格弹层） |
| ⌘/Ctrl + S | 保存当前文件 |
| ⌘/Ctrl + , | 打开设置 |
| ⌘/Ctrl + Enter | 跳转到相对 import/路径 |
| ⌘/Ctrl + [ | 返回上一跳转位置 |
| ⌘/Ctrl + ` | 打开终端会话标签 |
| ⌥/Alt + F1 | 在资源管理器中定位当前打开的文件 |
| Esc | 关闭 Quick Open / 设置 |

菜单栏亦支持 **查找文件 / 在文件中查找 / 在资源管理器中显示 / 打开终端**。

## 资源管理器

- **刷新**：标题栏刷新按钮；打开文件夹后会自动监听外部文件变更；窗口重新获得焦点时也会同步
- **定位当前文件**：十字准星按钮，或 **⌥F1**；展开祖先目录、滚动并高亮目标
- **过滤 / 定位文件**：顶部输入框过滤已加载节点，并异步检索全项目文件名；Enter 打开首条结果
- **折叠全部**：收起除根目录外的展开节点
- **外部改动**：磁盘文件被外部修改时，干净标签自动重载；有未保存更改时会询问是否覆盖
- 侧栏未折叠时，切换编辑标签会在树中自动跟随定位

## 终端会话（编辑区标签）

与 VS Code 底栏终端不同：Miro Code 将终端作为**与文件同级的编辑区标签**打开。

1. 点击活动栏左下角 **终端** 图标，或按 **⌘`**
2. 编辑区出现「终端」标签，内含左侧子导航：
   - **本地终端**：xterm + PTY，可多开（+）
   - **远程终端**：架构预留（后续 SSH）
   - **SFTP**：架构预留（后续远程文件 GUI）
3. 切换到其他文件标签时终端进程保持运行；关闭「终端」标签则结束会话

侧栏折叠：再次点击当前活动的资源管理器 / Git 图标即可。

## 搜索（对照 WebStorm）

不在左侧活动栏放置搜索入口，与 WebStorm 一致，通过快捷键唤起：

### 按文件名查找（⌘P）

对应 WebStorm「Go to File」：模糊匹配文件名，回车打开；支持最近搜索历史。

### 在文件中查找（⌘⇧F）

对应 WebStorm「Find in Files」：居中弹层，支持

- 文本查找 / 区分大小写
- 文件掩码（如 `ts,vue,md`）
- 替换预览与全部替换确认
- 结果列表 `路径:行号`，Enter 打开并关闭；⌘Enter 打开并保持弹层

## Git

侧边栏 Git 面板提供：

- 未初始化时可 **初始化仓库**
- **已暂存 / 更改** 分组列表，支持 stage / unstage
- 提交说明 + 提交
- 分支下拉：切换、新建、重命名、删除、合并
- 拉取 / 推送 / stash / stash pop
- Diff 弹层查看变更
- 提交历史与回退
- **冲突区**：保留本地(ours) / 保留远程(theirs) / 手动已解决
- **危险操作**（需确认）：硬重置、撤销提交、回退到指定 commit

状态栏显示当前分支；资源管理器文件名旁有 Git 状态色点。

## 编辑器

- 语法高亮：JS/TS/Vue/HTML/CSS/JSON/Markdown/YAML/XML/Env
- JSON 解析错误、`.env` 重复 key 诊断
- 基础关键字/snippet 与 Tailwind 常用类补全
- Markdown 文件可切换预览（marked）
- 代码折叠、lint gutter

## 主题

设置 → 编辑器 → 外观主题，四套可选：

- Miro Dark（默认深色）
- Miro Dawn（浅色）
- Miro Midnight（深蓝）
- Miro Cyberpunk（霓虹）

## AI 设置（占位）

设置中可配置 AI 补全开关、延迟、maxToken、触发字符，当前为 **本地占位**，不连接真实模型。

## 构建发布

```bash
pnpm release
```

等价于 `tauri build`，产出桌面安装包。
