# Miro Code 使用说明

## 快速开始

1. 启动应用：`pnpm tauri:dev`
2. 使用 **⌘O / Ctrl+O** 或欢迎页按钮打开本地文件夹
3. 在资源管理器中点击文件即可编辑

## 主界面

| 区域 | 说明 |
|---|---|
| 活动栏（左侧） | 上：Project / Commit；下：Git Log、终端、设置 |
| 侧边栏 | Project（资源管理器）或 Commit（暂存 / 更改） |
| 编辑区 | 多标签页：代码文件、Diff、**Git Log**、**终端**、**SSH** 同级打开；功能标签固定钉在右侧 |
| 状态栏 | 左侧：SSH 入口、根目录、分支、语言、编码、冲突数、LSP / AI 指示器；右侧：行列、缩进、主题 |

## 资源管理器

- **文件图标**：对齐 VS Code Material Icon Theme（按文件名 / 扩展名 / 常见文件夹名）
- **刷新**：标题栏刷新按钮（⌘R）；打开文件夹后自动监听外部文件变更；窗口重新获得焦点时也会同步
- **定位当前文件**：十字准星按钮，或 **⌥F1**；展开祖先目录、滚动并高亮目标
- **过滤 / 定位文件**：顶部输入框过滤已加载节点，并异步检索全项目文件名；Enter 打开首条结果
- **折叠全部**：收起除根目录外的展开节点
- **外部改动**：磁盘文件被外部修改时，干净标签自动重载；有未保存更改时会询问是否覆盖
- **右键菜单**：新建文件 / 文件夹、重命名、删除、复制 / 剪切 / 粘贴、复制绝对 / 相对路径、格式化文档
- **拖拽移动**：按住拖到目标文件夹移动文件（pointer 拖放实现）
- 侧栏未折叠时，切换编辑标签会在树中自动跟随定位；文件名旁有 Git 状态色点

## 编辑器

- **语法高亮**：JS / TS / Vue / HTML / CSS / SCSS / Sass / Less / JSON / Markdown / YAML / XML / SVG / Env
- **代码补全**：JS 关键字与片段、HTML 标签、CSS 属性、Tailwind 类名、当前文档词，以及 **LSP 语义补全**（TS / Vue）；输入即提示，⌘Space 手动触发
- **LSP 语言服务**（设置 → 编辑器 → 语言服务）：hover 悬浮文档、签名帮助、类型诊断、定义跳转、引用查找、重命名。支持两种运行方式：
  - **内置语言服务（推荐）**：设置内「一键安装」预打包的 Node + TS/Vue language server 到应用数据目录，不依赖宿主 Node；国内网络可选加速镜像
  - **宿主环境**：使用系统 Node + 项目 / 全局安装的 language server（自动检测），缺 Node 时相关能力降级为本地正则方案
- **诊断**：JSON 解析错误、`.env` 重复 key、LSP 类型诊断、ESLint（默认关闭）合流展示，lint gutter + 状态栏计数
- **格式化**：菜单 / 右键「格式化文档」，调用项目本地 Prettier（需已 `pnpm install`）
- **查找替换**：⌘F / ⌘⌥F，支持区分大小写、正则，替换有预览与确认
- **跳转**：相对路径与 `@/` 别名 import 跨文件跳转（⌘Enter）、同文件符号、跨文件符号索引；⌘[ 返回
- **Markdown 预览**：打开 `.md` 默认预览（可切源码），基于 marked
- **图片预览**：图片 / SVG 双击在编辑区预览
- **自动保存**：默认开启（1 秒防抖），设置中可关闭
- 有 Git 变更时，编辑区右键可「显示 Diff / 回滚变更」

## AI 行内补全（ghost text）

设置 → AI 配置分区（默认关闭）：

1. 打开开关，选择 provider（内置 **DeepSeek**，或 **自定义** OpenAI 兼容端点，填入 API Key 后自动填充地址与模型，可手动覆盖）
2. 输入代码时自动请求生成建议，灰色 ghost text 预览
3. **Tab 接受**、**Esc 取消**

可配置：多行策略（never / auto / always）、防抖延迟（默认 350ms）、首字提示延迟、Token 预算、温度、测试连接（点「测试连接」验证 API Key）。

- API Key 存储在 `~/.mirocode/ai-credentials.json`（权限 0600），不进浏览器存储
- 状态栏有 AI 指示器（就绪 / 思考中 / 错误）

## 终端会话（编辑区标签）

与 VS Code 底栏终端不同：Miro Code 将终端作为**与文件同级的编辑区标签**打开。

### 本地终端

1. 点击活动栏 **终端** 图标，或按 **⌘/Ctrl+J**
2. 编辑区出现「终端」标签，可多开；顶栏有 Package 快捷芯片（点击注入 `pnpm/npm/yarn/bun run …`）
3. 再次按 **⌘/Ctrl+J** 隐藏终端标签，**会话与 PTY 保持运行**；再按一次恢复
4. 切换到其他文件标签时会话同样保持；点击标签 **×** 才真正断开

### SSH 远程

1. 点击**状态栏左下角 SSH 按钮**，或活动栏 / 编辑区「SSH」标签
2. 主机列表：**添加主机 / 仅保存**写入主机列表；可勾选「记住密码」（存于 `~/.mirocode/ssh-credentials.json`）；首次连接未知主机需确认指纹（TOFU）
3. 连接后即进入**远程终端**：与本地终端互不干扰；输入与本地终端一致（Ctrl+C / 复制粘贴等通用快捷键）

### 切换项目

点击侧栏顶部**项目名称**可快捷切换：

- 最上方：**打开新项目…**
- 下方：最近项目列表
- 选择后提示 **本窗口打开** 或 **新窗口打开**

切换项目会强制关闭 SSH 远程连接并重建本地终端（cwd = 新项目根）。

## 搜索（对照 WebStorm）

不在左侧活动栏放置搜索入口，与 WebStorm 一致，通过快捷键唤起：

### 按文件名查找（⌘P）

对应 WebStorm「Go to File」：模糊匹配文件名，回车打开；支持最近搜索历史。

### 在文件中查找（⌘⇧F）

对应 WebStorm「Find in Files」：居中弹层，支持

- 文本查找 / 区分大小写
- 文件掩码（如 `ts,vue,md`）
- 替换预览与全部替换确认
- 结果列表 `路径:行号`，Enter 打开并关闭；⌘Enter 打开并保持弹层

## Git（对照 VS Code Source Control + Git Graph）

- **Commit（左侧）**：⌘K；「暂存的更改 / 更改」分组；单 / 批量暂存与取消；行内暂存·取消暂存·回滚；点文件在编辑区打开 Diff；Commit / Commit and Push（提交已暂存）；Amend 复选
- **变更状态字母**：`M` 已修改 · `U` 未跟踪 · `D` 已删除 · `C` 冲突；悬停可看说明
- **回滚**：更改列表行内 / 右键「回滚…」；编辑区对有变更的文件右键「回滚变更…」；未跟踪文件回滚会删除；回滚后编辑器内容会同步重载
- **工具栏图标**：Update Project（Fetch 后合并 / 变基）· Fetch（只下载）· Pull · Push · Stash 贮藏（计数徽章，可展开 apply / pop / drop）
- **Update / Fetch / Pull / Push**：Push 与 Update 为对话框（Merge / Rebase、Force push 需确认）
- **Branches**：状态栏分支 → 本地 / 远程弹层；右键含 Checkout、New Branch、Rename、Delete（本地 / 远程）、Merge into current、Rebase current onto、交互式 Rebase、Compare with current、Set upstream、Copy
- **Git Log（编辑区标签）**：活动栏 History 打开；列 Graph / Description / Date / Author / Commit；分支范围过滤（all / current）+ 远程开关 + 文本过滤 + Load More；行右键 Checkout / Cherry-pick / Revert / Reset（soft/mixed/hard）/ 交互式 Rebase / New Branch / Show Diff / Copy；双击行开 Diff
- **交互式 Rebase**：提交列表 pick / reword / squash / fix / drop + 拖拽排序；冲突时 Commit 横幅 Continue / Skip / Abort
- **登录**：HTTPS 需认证时弹账号密码；勾选「记住」写入 `~/.mirocode/git-credentials.json`（并尽力同步系统 Git 凭据）
- **冲突**：Commit 列表冲突横幅一键批量接受本地 / 远程；分栏合并（CompareView：左右双栏，prev / next 冲突导航，填入本地 / 远程 / Base，保留任一侧或手动编辑保存）；状态栏冲突数可点跳转

## 主题与语言

设置 → 编辑器 → 外观主题，四套可选：

- Miro Dark（默认深色，紫强调）
- Miro Dawn（浅色，蓝强调）
- Miro Midnight（深蓝，青蓝强调）
- Miro Cyberpunk（霓虹，青强调）

切换 UI 主题时编辑区代码高亮**同步切换**。状态栏主题名也可快捷切换（点击弹菜单，右键循环）。

设置左侧底部可切换**界面语言**：中文 / English；切换后活动栏、侧栏、编辑区、Git、搜索、终端、对话框以及 **macOS 顶部菜单栏**会同步变更，**无需重启**。

设置 → 编辑器还可配置：

- **自动保存**（默认开，可调延迟）/ **保存时格式化**（默认关）
- **ESLint** / **Prettier**（默认关闭；开启后调用当前项目的本地依赖，需已 `npm/pnpm install`）
- **移动文件时更新 import**（三态：询问 / 自动 / 关闭）
- **LSP 开关**与运行时状态；**内置语言服务**可一键安装（含 Node 运行时，不依赖宿主环境），支持镜像源选择与更新 / 卸载

## 更新

- 设置 → 系统 → **启动时自动检查**（默认开）：启动约 4 秒后静默检查，有新版本时右上角出现更新徽章
- **检查更新**：手动检查，确认后下载安装并重启
- 更新包来源：GitHub Release（`latest.json`），需签名校验

## 构建发布

本机当前平台：

```bash
pnpm release
```

多平台安装包与应用内更新：见 [多平台发布](多平台发布.md)。发版前请确认 `CHANGELOG.md` 与版本号已同步。
