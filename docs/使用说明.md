# Miro Code 使用说明

## 快速开始

1. 启动应用：`pnpm tauri:dev`
2. 使用 **⌘O / Ctrl+O** 或欢迎页按钮打开本地文件夹
3. 在资源管理器中点击文件即可编辑

## 主界面


| 区域      | 说明                                         |
| ------- | ------------------------------------------ |
| 活动栏（左侧） | 上：Project / Commit；下：Git Log、终端、设置等        |
| 侧边栏     | Project（资源管理器）或 Commit（暂存 / 更改）          |
| 编辑区     | 多标签页：代码文件、「终端」、**Git Log** 同级打开           |
| 状态栏     | 分支、语言、光标、主题                                |


## 快捷键


| 快捷键                | 功能                    |
| ------------------ | --------------------- |
| ⌘/Ctrl + O         | 打开文件夹                 |
| ⌘/Ctrl + P         | 按文件名查找并打开（Quick Open） |
| ⌘/Ctrl + Shift + F | 在文件中查找（WebStorm 风格弹层） |
| ⌘/Ctrl + S         | 保存当前文件                |
| ⌘/Ctrl + ,         | 打开设置                  |
| ⌘/Ctrl + Enter     | 跳转到相对 import/路径       |
| ⌘/Ctrl + [         | 返回上一跳转位置              |
| ⌘/Ctrl + J         | 显示 / 隐藏终端（隐藏时会话与进程保持）   |
| ⌘/Ctrl + B         | 折叠 / 展开左侧边栏                       |
| ⌘/Ctrl + K         | 打开 / 折叠左侧 Commit（WebStorm New UI） |
| ⌥/Alt + F1         | 在资源管理器中定位当前打开的文件      |
| Esc                | 关闭 Quick Open / 设置    |


菜单栏亦支持 **查找文件 / 在文件中查找 / 在资源管理器中显示 / 切换终端**。

## 资源管理器

- **文件图标**：对齐 VS Code Material Icon Theme（按文件名 / 扩展名 / 常见文件夹名）
- **刷新**：标题栏刷新按钮；打开文件夹后会自动监听外部文件变更；窗口重新获得焦点时也会同步
- **定位当前文件**：十字准星按钮，或 **⌥F1**；展开祖先目录、滚动并高亮目标
- **过滤 / 定位文件**：顶部输入框过滤已加载节点，并异步检索全项目文件名；Enter 打开首条结果
- **折叠全部**：收起除根目录外的展开节点
- **外部改动**：磁盘文件被外部修改时，干净标签自动重载；有未保存更改时会询问是否覆盖
- **右键菜单**：新建文件/文件夹、重命名、删除、复制/剪切/粘贴、复制绝对路径、复制相对路径
- 侧栏未折叠时，切换编辑标签会在树中自动跟随定位
- 文件名旁有 Git 状态色点

## 终端会话（编辑区标签）

与 VS Code 底栏终端不同：Miro Code 将终端作为**与文件同级的编辑区标签**打开。

1. 点击活动栏左下角 **终端** 图标，或按 **⌘/Ctrl+J**
2. 编辑区出现「终端」标签，左侧可选：
  - **本地终端**：本机 shell（xterm + PTY），可多开
  - **SSH**：主机卡片列表；「添加主机」保存连接信息（密码不落盘）；点击卡片连接。连接后可在顶部切换 **终端 / SFTP**（SFTP：单击选中、双击进入目录；右键新建/重命名/删除）
3. 再次按 **⌘/Ctrl+J**：隐藏终端标签，**会话与 PTY 保持运行**；再按一次恢复
4. 切换到其他文件标签时会话同样保持；点击标签 **×** 或关闭全部子终端即真正断开

### 切换项目

点击侧栏顶部**项目名称**可快捷切换：

- 最上方：**打开新项目…**
- 下方：最近项目列表
- 选择后提示 **本窗口打开** 或 **新窗口打开**

侧栏折叠：再次点击当前活动的资源管理器图标即可。

## 搜索（对照 WebStorm）

不在左侧活动栏放置搜索入口，与 WebStorm 一致，通过快捷键唤起：

### 按文件名查找（⌘P）

对应 WebStorm「Go to File」：模糊匹配文件名，回车打开；支持最近搜索历史。

### 在文件中查找（⌘⇧F）

对应 WebStorm「Find in Files」：居中弹层，支持

- 文本查找 / 区分大小写
- 文件掩码（如 `ts,vue,md`）
- 替换预览与全部替换确认
- 结果列表 `路径:行号`，Enter 打开并关闭；⌘Enter 打开并保持弹层

## Git（对照 VS Code Source Control + Git Graph）

- **Commit（左侧）**：⌘K；「暂存的更改 / 更改」分组；行内暂存·取消暂存·回滚；点文件在编辑区打开 Diff；Commit / Commit and Push（提交已暂存）
- **变更状态字母**：`M` 已修改 · `U` 未跟踪 · `D` 已删除 · `C` 冲突；悬停可看说明
- **回滚**：更改列表行内 / 右键「回滚…」；编辑区对有变更的文件右键「回滚变更…」；未跟踪文件回滚会删除；回滚后编辑器内容会同步重载
- **工具栏图标**：Update（Fetch 后合并/变基）· Fetch（只下载）· Pull · Push · Stash 贮藏
- **Update / Fetch / Pull / Push**：Push 与 Update 为对话框（Merge/Rebase、Force）
- **Branches**：状态栏分支 → 本地/远程弹层；右键含 Checkout、Merge、Rebase / Interactive Rebase、Compare、Set Upstream、Rename、Delete（本地/远程）、Copy
- **Git Log（编辑区标签）**：活动栏 History 打开；表格列 Graph / Description / Date / Author / Commit；右侧仅提交信息与变更文件；操作均在右键菜单（含 Cherry-pick）；可见 Uncommitted / Stash 行
- **贮藏 Stash**：Commit 工具栏贮藏后，列表上方出现「贮藏」分组（Apply / Pop / Drop）；Git Log 中也可见 stash 行；图标角标显示贮藏数量
- **交互 Rebase**：提交列表 pick/reword/squash/fixup/drop + 拖拽排序；冲突时 Commit 横幅 Continue / Skip / Abort
- **登录**：HTTPS 需认证时弹账号密码；勾选「记住」写入 `~/.mirocode/git-credentials.json`（并尽力同步系统 Git 凭据）
- **冲突**：Commit 列表批量接受；分栏合并（填入本地/远程/Base、上下冲突导航）；状态栏冲突数可点跳转

## 编辑器

- 语法高亮：JS/TS/Vue/HTML/CSS/JSON/Markdown/YAML/XML/Env
- **本地代码补全**：语言关键字、片段、当前文档词、Tailwind/CSS 提示；输入即提示，⌘Space 手动触发
- JSON 解析错误、`.env` 重复 key 诊断
- Markdown 文件可切换预览（marked）；图片可预览
- 代码折叠、lint gutter
- 有 Git 变更时，编辑区右键可「显示 Diff / 回滚变更」

不含 AI Agent、模型供应商或 MCP——定位为轻量本地编辑器。

## 主题与语言

设置 → 编辑器 → 外观主题，四套可选：

- Miro Dark（默认深色）
- Miro Dawn（浅色）
- Miro Midnight（深蓝）
- Miro Cyberpunk（霓虹）

设置左侧底部可切换**界面语言**：中文 / English；切换后活动栏、侧栏、编辑区、Git、搜索、终端、对话框以及 **macOS 顶部菜单栏**会同步变更，**无需重启**。

设置 → 编辑器还可配置：

- **自动保存** / **保存时格式化**
- **ESLint** / **Prettier**（默认关闭；开启后调用当前项目的本地依赖，需已 `npm/pnpm install`）
