# Miro Code 官方定名文档

Miro Code，是基于 Tauri \+ Vue3 构建的**轻量化、高颜值、全语法专业桌面代码编辑器**。产品采用 VSCode 经典灵活布局、Adnify 极简视觉 UI、WebStorm 标准的文件检索与 Git 管理体系，覆盖全主流开发语法的智能编辑能力，兼顾极致性能、极简颜值与专业编码体验。本文档为项目官方唯一品牌定名规范，所有项目文档、源码、产品展示统一使用该名称口径。

## 一、品牌官方释义

**Miro Code** 为项目唯一官方定名，名称由两大核心词根组合而成：**Micro（极致精简）\+ Mirror（精准镜像解析）**。寓意产品依托 Tauri 技术实现极致轻量化、低占用、极速运行的特性，同时以镜像级精准解析能力，实现全语法高亮、折叠、校验、自动补全、引用跳转等专业编码能力，是「轻量性能」与「专业能力」兼具的现代化代码编辑器。

释义：取自 Micro（极致精简）\+ Mirror（代码镜像精准解析），寓意软件体积精简、解析精准，既贴合 Tauri 轻量化特性，又适配全语法精准校验、跳转、补全的专业能力，文艺且专业。

## 二、品牌核心适配定位（官方统一口径）

**唯一官方定名：Miro Code**

产品定位统一口径：**高颜值极简轻量化、全语法全覆盖、类WebStorm专业功能、VSCode流畅布局的跨平台桌面代码编辑器**。

核心品牌优势（对外/文档/源码统一表述）：

- **轻量高性能**：基于 Tauri \+ Vue3 开发，告别传统编辑器臃肿卡顿，实现秒启动、低内存占用、跨平台流畅运行。

- **极简高颜值UI**：沿用 Adnify 极简低饱和视觉设计，沉浸式编辑界面，布局清爽、质感高级。

- **专业级功能**：资源管理器、全局检索、Git 版本管理完全对标 WebStorm 交互逻辑，功能成熟完备。

- **全语法智能编辑**：全覆盖主流前端、配置、文档语法，统一支持高亮、折叠、语法校验、代码补全、引用跳转。

- **高辨识度品牌**：原创组合命名，无主流编辑器重名，适配开源迭代与正式产品发布，可长期品牌沉淀。
