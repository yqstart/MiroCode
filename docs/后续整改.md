## 一、问题 1：Adnify 品牌脱钩（P0）

### 1.1 风险评估

| 风险点 | 现状 | 法律性质 | 等级 |
|---|---|---|---|
| 配色 token 复用 | `#0f0f12` / `#8b5cf6` 等颜色数值 | 不受保护（事实/思想） | 🟢 无 |
| CSS 变量结构 / 高亮 tag 映射 | 浅深底 + 关键字配色 | 不受保护（行业通用约定） | 🟢 无 |
| 主题 ID `"adnify-dark"` 硬编码进代码 | 5 处源码 + 1 处基准图 | 商标性使用风险 | 🟡 中 |
| 文档反复写"完全参照 Adnify" | 7 份文档存在 | 不正当竞争 / 傍名牌把柄 | 🟡 中 |
| `docs/theme2.png` 作为参考基准图 | 单张截图 | 内部参考使用风险低 | 🟢 低 |

> 注意：用户 `localStorage` 中已持久化的旧配置（`mirocode.settings.v1`）需要兼容读取。`loadSettings()` 已使用 `?? DEFAULT_SETTINGS.theme` 兜底，但旧值 `"adnify-dark"` 仍会被应用为非法主题。需要在 `loadSettings()` 中加迁移映射：
> ```ts
> const THEME_MIGRATION: Record<string, ThemeId> = { "adnify-dark": "miro-dark" };
> theme: THEME_MIGRATION[parsed.theme] ?? parsed.theme ?? DEFAULT_SETTINGS.theme

## 二、问题 2：开源合规 —— 第三方许可证聚合（P0）

### 2.1 风险评估

| 风险点 | 现状 | 法律性质 | 等级 |
|---|---|---|---|
| 项目根目录无 `LICENSE` 文件 | `Glob LICENSE*` 0 命中 | 仓库默认"版权所有"，与商用无关但需补 | 🟡 中 |
| 无 `THIRD-PARTY-NOTICES` 聚合文件 | 缺失 | 违反 MIT / Apache-2.0 义务（付费分发时硬伤） | 🟡 中 |
| 应用"关于"页未列出第三方致谢 | `SettingsModal.vue` 关于页仅作者信息 | 致谢缺失 | 🟡 中 |
| `git2` / `libgit2` GPL-2.0 with linking exception | 静态链接到产品 | **不传染**（linking exception 已豁免），仅需保留版权 | 🟢 无 |
| `tauri-plugin-pty` | 第三方 PTY 插件，MIT | OK | 🟢 无 |

### 2.2 整改动作

#### A. 仓库根新增 `LICENSE`

- [ ] 选择许可证：建议 **MIT**（最宽松，与依赖兼容性最好）
- [ ] 文件名：`LICENSE`
- [ ] 版权主体：MiroCode（或实际公司主体）
- [ ] 年份：2026

## 四、回滚预案

| 动作 | 回滚方式 |
|---|---|
| 主题 ID 重命名 | `git revert` 即可；用户配置通过 `THEME_MIGRATION` 反向兼容 |
| 文档话术修改 | `git revert`；不影响功能 |
| 新增 LICENSE / NOTICES | `rm` 文件即可，无破坏性 |
| 关于页改造 | `git revert`；不涉及持久化 |
