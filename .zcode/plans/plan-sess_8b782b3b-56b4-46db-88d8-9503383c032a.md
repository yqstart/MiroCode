### 设计：工作区级符号索引（纯前端 LRU）

#### 1. 新增 `src/features/editor/workspaceSymbols.ts`

```ts
// 符号 → 文件列表
export type WorkspaceSymbolIndex = Map<string, Array<{ path: string; line: number; column: number; kind: SymbolKind }>>;
// 文件 → 符号反向索引
export type ReverseSymbolIndex = Map<string, Set<string>>;
```

- 内存 LRU：≤ 500 个文件内容缓存（`Map`，LRU 淘汰）
- 增量失效：监听 `editor.tabs` + `workspace.refreshFromDisk`，对 dirty 文件每次重建
- 文件 mtime 缓存：`Map<path, mtime>` —— 未变文件跳过重建
- worker / setTimeout 异步构建：避免阻塞 UI 线程
- 启动时不构建：第一次跳转/引用时按需懒构建被涉及的文件
- 失败容错：单文件解析失败仅打 console.warn，不影响其他文件

#### 2. 跨文件 go-to-definition

扩展 `src/features/editor/navigation.ts::findTargetAtPosAsync`：
- 当前：先查当前文件 `findSymbolDefinition`（命中则同文件跳转）
- 扩展：未命中时 → 调 `workspaceSymbols.findDefinition(word, currentFile)` → 在所有 import 文件中查该符号导出

伪代码：
```ts
const def = findSymbolDefinition(doc, pos, filePath);
if (def) return { path: filePath, line: def.line, column: def.column, kind: "symbol" };
// 跨文件：查所有已 import 但未打开的文件 + 已打开文件
const workspaceDef = await workspaceSymbols.findDefinitionAcrossFiles(word, filePath);
return workspaceDef ?? null;
```

#### 3. 跨文件 find-references

新增 `src/features/editor/findReferences.ts`：
- 输入：当前光标单词
- 步骤 1：当前文件 `indexDocumentSymbols` + 文本扫描所有 `word` 出现位置
- 步骤 2：扫所有 import 当前文件的文件（反向 import 链），每个文件做步骤 1
- 步骤 3：去重 + 按 file/line 排序，返回 `{ path, line, column }[]`
- UI：复用现有搜索面板（`SearchPanel.vue`/`FindInFilesDialog.vue` 的结果展示样式），新增 tab "References"

#### 4. rename symbol

新增 `src/features/editor/renameSymbol.ts`：
- 输入：当前光标单词 + 新名
- 步骤 1：调 `findReferences` 拿全集
- 步骤 2：对每个引用点用 `editor.replaceRange`（CodeMirror StateEffect）替换
- 步骤 3：保存所有 dirty 文件
- 步骤 4：刷新工作区符号索引
- 触发：F2 键 / 右键菜单 "Rename Symbol"
- 冲突防护：单词必须匹配 `WORD_RE`（`[A-Za-z_$][\w$]*`）才允许触发

#### 5. UI 接入（最小化）

- **F2 键**：在 `goToDefinitionKeymap` 旁加 `renameKeymap`（`AppShell.vue` 或 `CodeMirrorEditor.vue` 复用 `isEditableTarget` 守卫）
- **References 面板**：复用 `FindInFilesDialog.vue` 的渲染，新增 tab "References (N)"
- **i18n 键**：`editor.renameSymbol` / `editor.references` / `editor.symbolNotFound`，zh/en 双语
- **进度反馈**：构建索引时 `showNotice("正在构建工作区符号索引…")`（仅 >1s 时显示）

### 风险点

| 风险 | 应对 |
|---|---|
| 大工作区 LRU 内存爆 | 上限 500 文件 + 单文件最大 1MB（超出截断） |
| .vue SFC template 段符号 | 明确仅解析 `<script>` 块（已有 `scriptSliceForVue`） |
| 异步构建阻塞 UI | 全部 `requestIdleCallback` 降级到 setTimeout 0；构建完成前返回 null，不阻塞跳转 |
| F2 与系统/CM 默认键冲突 | 复用 `isEditableTarget` 守卫；fallback 到右键菜单触发 |
| rename 时文件未保存导致脏读 | 先保存所有 dirty 文件再 rename |
| TS 高级类型 | 范围明确"不做"，i18n 提示用户用 TS Server 体验需用其他编辑器 |
